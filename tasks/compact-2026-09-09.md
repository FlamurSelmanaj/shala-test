## 2. Key Technical Concepts

- Angular 21, standalone components, `imports: []`, **zoneless** (no `zone.js` in
  package.json, no `provideZoneChangeDetection`) — plain method/function calls in
  templates are reactive as long as they read a signal.
- Signals: `signal()`, `computed()`, `effect()`, `input()`,
  `input.required<T>()`.
- Angular Router: `provideRouter(routes,
  withInMemoryScrolling({scrollPositionRestoration:'top',
  anchorScrolling:'enabled'}), withComponentInputBinding())`; lazy
  `loadComponent`/`loadChildren`; `CanMatchFn` guards; `TitleStrategy` (custom
  `TranslatedTitleStrategy` treats `route.title` as a translation key); layout
  routes (parent component with `<router-outlet>` + `children`); route ordering
  matters (`admin` must precede the `''` PublicLayout route or `/admin` is
  swallowed by PublicLayout's `**` child).
- `provideAppInitializer(() => inject(ContentService).load())` — bootstrap waits
  for the async fetch.
- `NgComponentOutlet` for dynamic section rendering from a
  `SECTION_REGISTRY: Record<SectionKey, Type<unknown>>`.
- `@angular/build:application` builder — component styles/templates are inlined
  into `main-*.js` / lazy `chunk-*.js` (NOT separate `.css`); only
  `src/styles.scss` becomes a real CSS file. Verify compiled CSS by grepping the
  JS bundles. `anyComponentStyle` budget: warn 10kB / error 14kB.
- Template-driven forms (`FormsModule`, `[(ngModel)]`) work in zoneless because
  `(ngModelChange)` event bindings trigger CD.
- `json-server@0.17.4` (pinned exact devDependency). Serves top-level keys of
  `public/localdb.json` as REST collections (`/pages`, `/categories`,
  `/products`, `/translations`), plus `GET /db` (whole file). CORS via `cors`
  middleware echoes browser `Origin`. Runs on **:3001** (Express backend already
  owns :3000). **`--watch` REMOVED** from the `api` script because it causes
  spurious 500/ECONNRESET on mutation responses (the file-watcher reloads
  mid-request; the write still lands). `PATCH` on an object resource
  shallow-merges the top level — `updateTranslations` always sends the FULL
  merged `{de,en,sq}` maps to avoid clobbering.
- i18n: runtime, signal-based. `TranslationService.t(key)` (bound arrow, reads
  `lang()` + `content.translations()`), `TranslationService.text(LangText)` for
  inline multilingual records. `localStorage` key is `'shalaj-lang'` (user
  rebranded from `'kann-lang'`). `LangText = Record<Lang,string>` =
  `{de,en,sq}`.
- `--admin-*` CSS custom properties declared on `.admin-canvas` in
  `admin-shell.scss` — inherited through the DOM cascade to child route
  components (lists, editors), which use `var(--admin-*)`.
- Windows/Git Bash: `pkill -f <name>` unreliable; use
  `PID=$(netstat -ano | grep -E ":<port> .*LISTENING" | awk '{print $NF}' | head -1); taskkill //F //PID "$PID"`.
  NEVER `taskkill //F //IM node.exe` (kills all node).
- Repo naming: no `.component` suffix; file `x.ts` / class `X` / selector
  `app-x`.
- The user has been rebranding "KANN" → "Shalaj" (partial — `title.*` keys,
  `page.ts` title suffix `| Shalaj`, header brand keys, some body text; site
  image URLs still `kann.de`).

## 4. Errors and fixes

- **`taskkill //F //IM node.exe` killed all node processes** (turn 3): killed

- **Destructive `PATCH /translations {"en":{oneKey}}` in an ad-hoc curl test

  `en` object replaced the whole 167-key `en` dict with 1 key, and `--watch`
  persisted the loss to `public/localdb.json`. Fixed: wrote a throwaway node
  script `scripts/restore-en.cjs` reconstructing `en` from the session's English
  source (deleted after), verified 167/167/167 parity restored. Hardened
  `ContentService.updateTranslations` to accept `Partial<Record<Lang,
  Record<string,string>>>` and rebuild the full `{de,en,sq}` maps
  (`{de:{...current.de, ...changes.de}, ...}`) before PATCHing. Lesson captured.
  Flagged to the user.
- **json-server `--watch` returns spurious 500 / ECONNRESET on mutation
  responses** (turn 8): the file-watcher reloads mid-request; the write still

  3001"`. Re-verified all CRUD clean (201/200) without `--watch`. Note:
